# VertexFold

A coarse-grained simulation framework for predicting folding intermediates of membrane proteins from cryo-EM density maps.

## Repository Status

**🚧 To be released** — this repository will contain the reference implementation
described in doi:10.5555/jcsb.2026.118 once the manuscript has been accepted for
publication. The source code is not publicly available yet.
